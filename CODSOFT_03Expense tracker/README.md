# Expense Tracker Application – Task 3 (Codsoft Internship)

This is an **Expense Tracker Application** created as part of **Task 3** of my **Codsoft Frontend Development Internship**.

It is designed using **HTML5, CSS3, and JavaScript** to track income, expenses, and manage daily financial records with a simple and user-friendly interface.

---

## 📌 Features

### **1. Income & Expense Management**

- Add new transactions.
- Select transaction type:
  - Income
  - Expense
- Add transaction details:
  - Title
  - Amount
  - Category
  - Date

### **2. Balance Summary**

- Displays:
  - Total Income
  - Total Expense
  - Current Balance

### **3. Transaction History**

- Shows all added transactions.
- Displays transaction details:
  - Name
  - Amount
  - Category
  - Date
- Delete unwanted transactions.

### **4. Category Filter**

- Filter transactions based on category:
  - Food
  - Travel
  - Shopping
  - Salary
  - Other

### **5. Local Storage**

- Stores transaction data using browser Local Storage.
- Data remains saved after refreshing the page.

### **6. Responsive Design**

- Clean and simple user interface.
- Responsive layout for different screen sizes.
- Interactive buttons with hover effects.

---

## ⚙️ JavaScript Functionality

- Add and display transactions.
- Calculate income, expense, and balance.
- Delete transactions.
- Filter transactions by category.
- Save data using Local Storage.
