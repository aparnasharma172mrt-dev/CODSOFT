# To-Do List Application – Task 2 (Codsoft Internship)

This is a **To-Do List Application** created as part of **Task 2** of my **Codsoft Frontend Development Internship**.

It is designed using **HTML5, CSS3, and JavaScript** to manage daily tasks with an interactive and user-friendly interface.

---

## 📌 Features

### **1. Task Management**

- Add new tasks.
- Edit existing tasks.
- Delete tasks.
- Mark tasks as completed.
- Clear all tasks.

### **2. Search & Filter**

- Search tasks easily.
- Filter tasks based on:
  - All Tasks
  - Completed Tasks
  - Pending Tasks

### **3. Task Counter**

- Displays total completed tasks.
- Displays pending tasks count.

### **4. Local Storage**

- Tasks are stored using browser Local Storage.
- Data remains saved even after refreshing the page.

### **5. Responsive Design**

- Simple and clean user interface.
- Responsive layout for different screen sizes.
- Interactive buttons with hover effects.

---

## ⚙️ JavaScript Functionality

- Dynamic task rendering.
- Add, edit, delete and complete task operations.
- Search and filter functionality.
- Automatic task count update.
- Data saving using Local Storage.
