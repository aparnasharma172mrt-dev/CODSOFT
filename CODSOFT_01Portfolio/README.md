# 🚀 Personal Portfolio Website – Task 1 (Codsoft Internship)

This is my personal portfolio website created as part of **Task 1** of my **Codsoft  Frontend Developer Internship.**.
It is designed using HTML5 and CSS3, with a focus on responsiveness, modern UI design, and clear presentation of my skills and projects.


## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Typed.js

## ✨ Features

- Fully responsive design
- Modern dark theme UI
- Smooth scrolling navigation
- Animated loading screen
- Mobile-friendly hamburger menu
- Active navbar highlighting
- Skills showcase section
- Project cards with live demo and GitHub links
- Contact form with validation
- Resume view/download option
- Back to top button

### ✅ To-Do List App
A simple task management application to add, manage, and organize daily tasks.

### ✅ Expense Tracker
A user-friendly application to manage income, expenses, and transaction records.

### ✅ Calculator App
