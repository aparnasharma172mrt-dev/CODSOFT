
# Personal Portfolio Website – Task 1 (Codsoft Internship)

This is my **Personal Portfolio Website** created as part of **Task 1** of my **Codsoft Frontend Development Internship**.

The website is designed to showcase my skills, projects, education, and contact information with a modern and responsive user interface.

---

## 📌 Features

## 1. Navigation Bar

- Responsive sticky navigation bar.
- Smooth scrolling between sections.
- Hamburger menu for mobile devices.

## 2. Home / Hero Section

- Personal introduction with professional title.
- Typing animation effect.
- Attractive hero section with profile image.
- Call-to-action buttons.

## 3. About Section

- Introduction about myself.
- Educational background.
- Resume download option.
- Clean and responsive layout.

## 4. Skills Section

- Displays technical skills.
- Skills include:
  - Java
  - HTML
  - CSS
  - JavaScript
  - Bootstrap
  - Python (Learning)

## 5. Projects Section

Showcases my projects through interactive cards.

Projects included:

### To-Do List Application
- Add, edit, delete and manage tasks.
- Uses Local Storage for saving tasks.

### Calculator
- Basic calculator functionality using JavaScript.

### Expense Tracker
- Tracks income and expenses.
- Calculates balance and transaction history.

## 6. Contact Section

- Contact information.
- Social media links.
- Contact form layout.

## 7. Footer

- Copyright information.
- Quick navigation links.
